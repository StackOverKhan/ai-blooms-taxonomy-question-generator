# 📘 AI-Powered Bloom’s Taxonomy Question Generator

## 🚀 Overview
The **AI-Powered Bloom’s Taxonomy Question Generator** is a web-based application designed to help educators, faculty members, and academic institutions create **outcome-oriented exam questions** efficiently.

Instead of relying on memory-based or repetitive questions, this system leverages **Google Gemini AI** to generate questions aligned with **Bloom’s Taxonomy cognitive levels**, ensuring higher-order thinking and better learning assessment.

---

## 🎯 Problem Statement
Creating quality exam questions that align with Bloom’s Taxonomy is:
- Time-consuming for educators  
- Often inconsistent across subjects  
- Prone to focusing only on recall-based learning...  

There is a need for an **intelligent, automated system** that assists educators in generating **pedagogically sound questions** quickly and reliably.

---

## 💡 Solution
This application provides an AI-driven solution where users can:
- Select a subject and topic  
- Choose the desired Bloom’s Taxonomy level  
- Instantly generate well-structured exam questions  

The system ensures that questions match the **intended cognitive level**, supporting modern outcome-based education frameworks.

---

## ✨ Key Features
- Subject and topic-based question generation  
- Bloom’s Taxonomy cognitive level selection  
- Outcome-oriented exam questions  
- Real-time AI-powered generation  
- Clean, minimal, and intuitive user interface  

---

## 🛠️ Tech Stack
- **Python 3.11**
- **Streamlit** – Web application framework
- **Google Gemini API** – AI-based content generation

---

## 🤖 Google Technologies Used
- **Google Gemini (Flash / Lite)** for real-time natural language generation

---

## ⚙️ How It Works
1. User enters the subject and topic  
2. User selects the Bloom’s Taxonomy level  
3. The request is sent to Google Gemini AI  
4. AI generates five outcome-based exam questions  
5. Questions are displayed instantly in the interface  

---

## ▶️ Run Locally
```bash
pip install streamlit google-generativeai

```
